## git commit提交说明

```
  git commit -m "type: 提交说明"
  如: git commit -m "fix: 修复bug2135中不能删除用户"
```
 ```
  type说明提交的性质，后面的英文冒号和“提交说明”间留一-个空格，type值如下:

  feat: 添加新特性
  fix: 修复bug
  docs: 仅仅修改了文档
  style: 仅仅修改了空格、格式缩进、逗号等等，不改变代码逻辑
  refactor: 代码重构，没有加新功能或者修复bug
  perf: 优化相关，比如提升性能、体验
  test: 增加测试用例
  chore: 改变构建流程、或者增加依赖库、工具等
  revert: 回滚到上一个版本
 ```
